🧲 Extracto

Collez une URL YouTube (ou partagez-la depuis WhatsApp) : obtenez un résumé structuré, les points clés, et une vérification des faits annoncés.

⚠️ Aucune clé API Anthropic enregistrée. pour pouvoir analyser une vidéo.

Les vérifications de faits sont générées par une IA qui effectue des recherches web en temps réel pour chaque affirmation, avec ta propre clé API Anthropic. Les sources sont indiquées, mais vérifie toujours les points importants par toi-même.

Paramètres

Stockée uniquement sur cet appareil, jamais envoyée ailleurs qu'à Anthropic.

Je n'ai pas encore de clé — comment en obtenir une ?
  1. Va sur console.anthropic.com et crée un compte (avec Google ou ton adresse e-mail).
  2. Dans le menu Billing, ajoute quelques dollars de crédit (5 $ suffisent pour de nombreuses analyses).
  3. Dans le menu API Keys, touche Create Key, donne-lui un nom, puis copie la clé affichée (elle commence par sk-ant-...) — elle ne sera montrée qu'une seule fois.
  4. Reviens ici, colle-la dans le champ ci-dessus, puis touche Enregistrer.
