🧲 Extracto

Collez une URL YouTube (ou partagez-la depuis WhatsApp) : obtenez un résumé structuré, les points clés, et une vérification des faits annoncés.

⚠️ Aucune clé API Claude enregistrée. pour pouvoir analyser une vidéo, ou choisis Google Gemini (gratuit, sans clé requise) dans les Paramètres.

Les vérifications de faits sont générées par une IA qui effectue des recherches web en temps réel pour chaque affirmation. Les sources sont indiquées, mais vérifie toujours les points importants par toi-même.

Paramètres

Par défaut, l'app utilise une clé Gemini déjà configurée : tu n'as rien à faire. Renseigne ta propre clé uniquement si tu préfères utiliser ton propre quota Gemini (stockée uniquement sur cet appareil).

Je préfère utiliser ma propre clé Gemini — comment en obtenir une ?
  1. Va sur aistudio.google.com/apikey et connecte-toi avec un compte Google (100 % gratuit, aucune carte bancaire requise).
  2. Touche Create API key, choisis un projet (ou laisse celui proposé par défaut).
  3. Copie la clé affichée (elle commence par AIza...).
  4. Reviens ici, colle-la dans le champ ci-dessus, puis touche Enregistrer.
Je n'ai pas encore de clé Anthropic — comment en obtenir une ?
  1. Va sur console.anthropic.com et crée un compte (avec Google ou ton adresse e-mail).
  2. Dans le menu Billing, ajoute quelques dollars de crédit (5 $ suffisent pour de nombreuses analyses).
  3. Dans le menu API Keys, touche Create Key, donne-lui un nom, puis copie la clé affichée (elle commence par sk-ant-...) — elle ne sera montrée qu'une seule fois.
  4. Reviens ici, colle-la dans le champ ci-dessus, puis touche Enregistrer.
